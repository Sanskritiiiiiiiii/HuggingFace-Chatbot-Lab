# 🤖 HuggingFace-Chatbot-Lab

A conversational AI chatbot project built using Hugging Face Transformers and BlenderBot.  
This project demonstrates how to create an interactive chatbot using pretrained NLP models.

---

## 🚀 Features

- Conversational AI chatbot
- Uses Hugging Face Transformers
- BlenderBot pretrained model
- Interactive chat interface in Jupyter Notebook
- Natural language response generation

---

## 🛠️ Technologies Used

- Python
- Hugging Face Transformers
- BlenderBot
- PyTorch
- Jupyter Notebook

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/HuggingFace-Chatbot-Lab.git
```

Move into the project directory:

```bash
cd HuggingFace-Chatbot-Lab
```

Install dependencies:

```bash
pip install transformers torch
```

---

## ▶️ Usage

Open the notebook:

```bash
jupyter notebook
```

Run:

```bash
HF_BlenderChat.ipynb
```

Start chatting with the AI chatbot.
